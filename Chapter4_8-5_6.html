            Section 4.8 • 報告人：建廷
            
一、生產與成本函數習題演算

          

          
        


        

          
          

            
1. 擴張路徑（Expansion Path）推導

            

              給定邊際技術替代率 $MRTS_{LK} = \frac{MP_L}{MP_K}$ 與要素價格比率 $\frac{w}{r}$，廠商追求成本極小化的一階必要條件為等產量線斜率等於等成本線斜率：
            

            

              $$MRTS_{LK} = \frac{MP_L}{MP_K} = \frac{w}{r}$$
            

            

              非線性擴張趨勢特徵：在本題設定的生產函數中，不同於齊次（Homothetic）生產函數的射線型擴張路徑，隨著生產規模 $Q$ 持續擴大，最佳要素投入組合的勞資比 $\frac{L}{K}$ 會沿著曲線逐漸趨近於固定的漸近常數比率。
            

          


          
          

            
2. 四種生產函數之規模報酬判定（將投入 $(L, K)$ 同乘 $t > 1$ 倍）

            

              

                
                  

                    生產函數形式 $Q = f(L, K)$
                    投入放大 $t$ 倍後 $f(tL, tK)$
                    規模報酬類型
                    經濟判定準則
                  

                
                
                  

                    $Q = aL + bK$（線性）
                    $t(aL + bK) = tQ$
                    規模報酬固定 (CRS)
                    產出等比例增加（一次齊次）
                  

                  

                    $Q = A L^\alpha K^\beta \ (\alpha + \beta > 1)$
                    $t^{\alpha+\beta} A L^\alpha K^\beta = t^{\alpha+\beta} Q > tQ$
                    規模報酬遞增 (IRS)
                    產出增幅大於投入增幅
                  

                  

                    $Q = \min\{\frac{L}{a}, \frac{K}{b}\}$（Leontief）
                    $\min\{\frac{tL}{a}, \frac{tK}{b}\} = tQ$
                    規模報酬固定 (CRS)
                    完全互補要素，等比例擴張
                  

                  

                    $Q = A L^\alpha K^\beta \ (\alpha + \beta < 1)$
                    $t^{\alpha+\beta} A L^\alpha K^\beta = t^{\alpha+\beta} Q < tQ$
                    規模報酬遞減 (DRS)
                    管理協調負荷導致產出增幅趨緩
                  

                
              

            

          


          
          

            
3. 三次總成本函數與平均、邊際成本極值

            

              給定無固定成本之三次總成本函數 $C(q) = aq^3 - bq^2 + cq$（其中 $a, b, c > 0$ 且 $b^2 < 3ac$ 確保邊際成本恆正）：
            

            

              

                
平均成本最低點（Minimum AC）

                

                  平均成本 $AC(q) = \frac{C(q)}{q} = aq^2 - bq + c$。令一階導數 $\frac{dAC}{dq} = 2aq - b = 0$：
                

                

                  $$q^*_{AC} = \frac{b}{2a}, \quad \text{此時 } MC(q^*_{AC}) = AC(q^*_{AC}) = c - \frac{b^2}{4a}$$
                

              


              

                
邊際成本最低點（Minimum MC / 反曲點）

                

                  邊際成本 $MC(q) = \frac{dC}{dq} = 3aq^2 - 2bq + c$。令一階導數 $\frac{dMC}{dq} = 6aq - 2b = 0$：
                

                

                  $$q^*_{MC} = \frac{b}{3a}, \quad \text{此時 } MC_{\min} = c - \frac{b^2}{3a}$$

              1
              
團隊規模與規模報酬（橫向比較）

            

            

              當團隊人數由 1、2、4、6、8 人逐步擴大時，初期因專業化分工（專人折機頭、折機翼、摺尾翼與試飛品管）大幅減少動作切換時間，使每人平均產出上升（展現規模報酬遞增 IRS）；但當人數過多時，受限於桌面空間擁擠與溝通協調瓶頸，每人平均產出增幅趨緩甚至下滑（轉入規模報酬遞減 DRS）。
            

          


          

            

              2

              在團隊人數固定下，隨著第 1 至第 4 回合重複操作，成員累積操作熟練度並改良折疊治具與流程，使每單位時間的合格良率與總產量持續攀升、單位生產時間下降，在圖形上表現為整條平均成本曲線向下移動，展現典型的學習曲線（Learning Curve）。
            

          

        

      


      
      

        

          Sections 5.1 & 5.4 • 報告人：語沛 ＆ 奕如
          
三、完全競爭廠商決策與四大市場結構比較

        


        
        

          
1. 經濟利潤（Economic Profit） vs. 會計利潤（Accounting Profit）

          

            

              總收益（Total Revenue）
              
$TR = P \times q$

            

            

              會計利潤（Accounting Profit）
              
$\pi_{\text{acct}} = TR - \text{外顯成本 (Explicit Costs)}$

            

            

              經濟利潤（Economic Profit）
              
$\pi_{\text{econ}} = TR - (\text{外顯成本} + \text{隱藏／機會成本})$

            

          

          

            核心觀念（正常利潤 Normal Profit）：當經濟利潤 $\pi_{\text{econ}} = 0$ 時，並非企業經營虧損或失敗，而是代表企業所賺取的會計利潤剛好足以支付所有自有資金、時間與才能的機會成本，因此廠商沒有誘因退出該產業。
          

        


        
        

          
2. 四大市場結構核心特徵比較

          

            

              
                

                  市場結構
                  廠商數量
                  產品性質
                  定價能力
                  課堂與生活實例
                

              
              
                

                  完全競爭市場
                  眾多（無數家）
                  完全同質（Homogeneous）
                  價格接受者（Price Taker）
                  大宗農產品（玉米、黃豆期貨）、外匯現貨
                

                

                  獨佔市場
                  僅一家
                  無相近替代品
                  價格決定者（Price Maker）
                  具獨家關鍵專利的特殊晶片技術、自來水/電網公用事業
                

                

                  獨佔性競爭
                  眾多
                  具差異性（Differentiated）
                  有限定價能力
                  手搖飲店（50嵐、CoCo）、連鎖咖啡（星巴克、路易莎）
                

                

                  寡佔市場
                  少數幾家
                  同質或異質
                  相互依賴（策略互動）
                  四大超商（7-ELEVEN、全家促銷戰）、電信三雄
                

              
            

          

        

      


      
      

        

          

            Section 5.3 • 報告人：辰鴻
            
四、個別廠商供給、長期產業供給與彈性

          

          
        


        

          

            
1. 個別廠商短期與長期供給曲線

            

              完全競爭廠商追求利潤極大化，一階條件為 $P = MC(q)$。當市場價格低於最低平均變動成本（$P < AVC_{\min}$，短期歇業點）或最低平均總成本（$P < AC_{\min}$，長期退出點）時，廠商最佳產量為 $q = 0$。因此，個別廠商的供給曲線即為最低平均成本（或平均變動成本）點以上的邊際成本（$MC$）上升段。
            

          


          

            
2. 自由進出與四類長期產業供給曲線（Long-Run Industry Supply, $LRS$）

            

              長期下廠商可自由進出市場，短期超額利潤會吸引新廠商進入、使市場供給右移並壓低價格，直到所有廠商經濟利潤歸零（$P = AC_{\min}$）。依據產業規模擴張對要素價格與外部性的影響，長期產業供給曲線分為四類：
            

            

              

                
① 成本不變產業（Constant-Cost Industry）

                
產業擴張不影響生產要素價格與外部性，各廠商 $AC_{\min}$ 維持不變，長期產業供給曲線為水平線（完全彈性）。

              

              

                
② 成本遞增產業（Increasing-Cost Industry）

                
產業擴張引發負外部性或推升稀缺要素價格（如土地租金飆升），使 $AC$ 整條上移，長期供給曲線為正斜率。

              

              

                
③ 成本遞減產業（Decreasing-Cost Industry）

                
產業群聚（Clustering）帶來正外部性、基礎建設完善或共用設備成本下降，使 $AC$ 下移，長期供給曲線為負斜率。

              

              

                
④ 後彎型長期供給曲線（Backward-Bending）

                
如海洋漁業，當魚價過高引發過度捕撈（Overfishing）導致魚群再生資源枯竭時，價格再上升反而使長期總漁獲供給量萎縮。

              

            

          


          

            
3. 供給價格彈性（Price Elasticity of Supply, $\varepsilon_s$）

            

              

                弧彈性（Arc Elasticity）
                $$\varepsilon_s = \frac{\Delta Q / \bar{Q}}{\Delta P / \bar{P}} = \frac{(Q_2 - Q_1)/(Q_1 + Q_2)}{(P_2 - P_1)/(P_1 + P_2)}$$
              

              

                點彈性（Point Elasticity）
                $$\varepsilon_s = \frac{dQ}{dP} \cdot \frac{P}{Q}$$
              

            

            

              判別標準：$\varepsilon_s = 0$ 為完全無彈性（垂直供給線，如土地總量固定）；$\varepsilon_s = 1$ 為單位彈性；$\varepsilon_s > 1$ 為富有彈性；$\varepsilon_s \to \infty$ 為完全彈性（水平供給線）。

五、利潤極大化三步驟與長期均衡計算

          

          
        


        

          
          

            

              
1. 利潤極大化三步驟與實例檢驗（裕芳）

              Ex 5.1 & 5.2
            

            
    
              
  1. 邊際條件求解（FOC）：令 $P = MC(q)$ 求解所有候選產量。
    2. 
              
  2. 二階條件與合理性篩選（SOC）：剔除負產量（$q < 0$），並確認 $\frac{dMC}{dq} > 0$（即 $MC$ 處於上升階段）。
    3. 
              
  3. 歇業條件檢驗：確認 $P \ge AC_{\min}$（長期）或 $P \ge AVC_{\min}$（短期），再計算總利潤 $\pi = Pq - C(q)$。
    4. 
            


            

              
📌 Exercise 5.1 演算範例：

              
已知 $C(q) = q^3 - 6q^2 + 15q$，則 $MC(q) = 3q^2 - 12q + 15$，$AC(q) = q^2 - 6q + 15$。

              
當市場價格 $P = 15$ 時：

              
    
                
  • 令 $3q^2 - 12q + 15 = 15 \Rightarrow 3q(q - 4) = 0$，得 $q = 4$（剔除 $q = 0$）。
    • 
                
  • 檢驗最低平均成本：$AC(4) = 16 - 24 + 15 = 7$，因 $P = 15 > 7$ 繼續生產。
    • 
                
  • 計算最大經濟利潤：$\pi = (15 - 7) \times 4 = \mathbf{32}$。
    • 
              

            

          


          
          

            

              
2. 從短期超額利潤到長期競爭均衡（晨熙）

              Ex 5.5 & 5.6
            

            

              已知每家廠商的總成本與邊際成本函數為：
              $$C(q) = q^3 - 12q^2 + 60q + 100, \quad MC(q) = 3q^2 - 24q + 60$$
            


            

              

                
① 單一廠商短期決策（Exercise 5.5）

                

                  當市場價格 $P = 60$ 時，令 $3q^2 - 24q + 60 = 60 \Rightarrow 3q(q - 8) = 0$，得 $q = 0$（利潤極小點，$MC$ 遞減）或 $q = 8$（利潤極大點，$MC$ 遞增）。此時 $AC(8) = \frac{512 - 768 + 480 + 100}{8} = 40.5$，單一廠商獲得超額利潤：
                  $$\pi = (60 - 40.5) \times 8 = \mathbf{156}$$
                

              


              

                
② 長期自由進出均衡（Exercise 5.6）

                

                  超額利潤吸引新廠商進入，價格一路下跌至最低平均成本處。令 $MC(q) = AC(q)$：
                  $$3q^2 - 24q + 60 = q^2 - 12q + 60 + \frac{100}{q} \Rightarrow 2q^3 - 12q^2 - 100 = 0 \Rightarrow q^* = \mathbf{5}$$
                  此時長期均衡價格 $P^* = MC(5) = \mathbf{15}$，各廠商經濟利潤 $\pi = 0$。若市場總需求為 $Q_D = 1230 - 2P$，代入 $P^* = 15$ 得產業總產量 $Q^* = 1200$，因此市場容納的均衡廠商總家數為：
                  $$N^* = \frac{Q^*}{q^*} = \frac{1200}{5} = \mathbf{240\text{ 家}}$$

            Seminar Discussion
            
💬 課堂研討與思考問題（點擊展開理論解析提示）

          


          

            
            

              
                問題 1：自然資源與後彎型供給曲線 — 除了海洋漁業與森林木材之外，現代經濟中還有哪些資源可能出現供給曲線後彎或垂直無彈性的現象？
                展開提示
                收合
              
              

                
1. 完全無彈性（垂直供給線 $\varepsilon_s = 0$）：

                
    
                  
  • 制度性總量管制配額：例如歐盟與台灣的「碳排放交易配額（Cap-and-Trade）」、政府釋出的 5G 頻譜執照、或央行基於總體審慎監理（Macroprudential Policy）所設定的銀行體系不動產放款總量上限。
    • 
                  
  • 稀土與特定稀有金屬短期開採：受限於礦場環評與提煉產能建設週期（長達 5~10 年），短期內即便價格翻倍，產量也幾乎呈現垂直無彈性。
    • 
                

                
2. 後彎型供給曲線（Backward-Bending Supply）：

                
    
                  
  • 高階專業勞動供給：當醫師、律師或頂尖工程師的時薪極高時，所得效果（Income Effect，偏好更多休閒時間）大於替代效果，導致工時隨著工資上升而減少。
    • 
                  
  • 地下水層超抽與地層下陷：農漁業或工業在高水價／高產值誘因下過度抽取地下水，導致含水層壓密枯竭，長期反而使可抽取總水量銳減。
    • 
                

              

            


            
            

              
                問題 2：完全競爭長期零利潤的迷思 — 既然完全競爭市場長期經濟利潤為零，為何現實中仍有大量創業者願意投入餐飲、農產或零售業？
                展開提示
                收合
              
              

                
1. 「經濟利潤為零」$\neq$「沒有賺錢（會計利潤為零）」：

                

                  長期均衡 $\pi_{\text{econ}} = 0$ 代表創業者賺取了完整的正常利潤（Normal Profit），也就是足以支付其自有資金的市場利息、自有店面的市場租金，以及創業者本人在外受僱可領取的市場薪資（機會成本）。對創業者而言，這代表「自己當老闆的報酬不亞於去外面幫別人打工」。
                

                
2. 異質性廠商與李嘉圖租（Ricardian Rent）及短期動態套利：

                

                  現實中各創業者管理能力與店面區位不同，具備較低邊際成本的「邊際內廠商（Intra-marginal firms）」仍能長期享有生產者剩餘；此外，透過產品差異化（轉向獨佔性競爭）或流程創新，創業者能在競爭者模仿前賺取短期超額利潤。
