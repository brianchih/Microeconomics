一、 建廷：Section 4.8 生產與成本函數習題演算

1. 擴張路徑（Expansion Path）推導

給定邊際技術替代率與要素價格比率 $\frac{w}{r} = 2$，成本極小化條件為：

$$MRTS_{L,K} = \frac{L - 1}{K} = \frac{w}{r} = 2 \implies L = 2K + 1 \quad (L \ge 1)$$

隨著生產規模擴大，勞資比 $\frac{L}{K} = 2 + \frac{1}{K}$ 會逐漸趨近於 $2$。

2. 四種生產函數之規模報酬判定（將 $K, L$ 同乘 $\lambda > 1$）

生產函數 投入放大 $\lambda$ 倍後 規模報酬類型
$Q = 3K + 4L$ $3(\lambda K) + 4(\lambda L) = \lambda Q$ 規模報酬固定 (CRS)
$Q = 0.5KL$ $0.5(\lambda K)(\lambda L) = \lambda^2 Q > \lambda Q$ 規模報酬遞增 (IRS)
$Q = \min(3K, 4L)$ $\min(3\lambda K, 4\lambda L) = \lambda Q$ 規模報酬固定 (CRS)
$Q = 6K^{1/3}L^{1/3}$ $6(\lambda K)^{1/3}(\lambda L)^{1/3} = \lambda^{2/3} Q < \lambda Q$ 規模報酬遞減 (DRS)

3. 三次總成本函數與平均、邊際成本極值

給定總成本函數 $TC(Q) = Q^3 - 30Q^2 + 301Q$：

$$AC(Q) = \frac{TC(Q)}{Q} = Q^2 - 30Q + 301$$ $$MC(Q) = \frac{d\,TC(Q)}{dQ} = 3Q^2 - 60Q + 301$$
  • 平均成本最低點： 令 $\frac{d\,AC}{dQ} = 2Q - 30 = 0 \implies Q = 15$，此時 $AC(15) = 15^2 - 30(15) + 301 = 76$。
  • 邊際成本最低點： 令 $\frac{d\,MC}{dQ} = 6Q - 60 = 0 \implies Q = 10$，此時 $MC(10) = 3(10^2) - 60(10) + 301 = 1$。

二、 斯育：Section 4.9 規模經濟與做中學實驗

透過「紙飛機折疊生產線」實驗（每回合 4 分鐘規劃分工、3 分鐘實際折疊與試飛品管，共進行 4 回合），同時觀察兩種動態與規模效應：

1. 團隊規模與規模報酬（橫向比較）

當團隊人數由 1、2、4、6、8 人逐步擴大時，初期因專業化分工（折機身、折機翼、品管測試）使平均產出上升（IRS）；但當人數過多時，受限於空間與溝通協調成本，產出增幅趨緩甚至下降（DRS）。

2. 做中學效應（Learning by Doing，縱向比較）

隨著第 1 至第 4 回合重複操作，成員累積經驗並改良折疊流程，使每單位時間的良率與產量持續攀升，展現典型的學習曲線（Learning Curve）。

三、 語沛 ＆ 奕如：第5章 完全競爭廠商決策與市場結構（5.1 & 5.4）

1. 經濟利潤 vs. 會計利潤

$$\text{總收益：} TR = P \times Q$$ $$\text{會計利潤} = TR - \text{外顯成本（Explicit Costs）}$$ $$\text{經濟利潤 } (\pi) = TR - (\text{外顯成本} + \text{隱藏成本／機會成本})$$

當經濟利潤 $\pi = 0$ 時，並非企業經營失敗，而是代表企業所賺取的收益剛好足以支付所有資源的機會成本（即獲得「正常利潤 Normal Profit」）。

2. 四大市場結構比較

市場結構 廠商數量 產品性質 定價能力 課堂與生活實例
完全競爭市場 眾多 完全同質 價格接受者（Price Taker） 大宗農產品（玉米、黃豆期貨）
獨佔市場 僅一家 無相近替代品 價格決定者 具獨家關鍵專利的特殊晶片技術、公用事業
獨佔性競爭 眾多 具差異性 有限定價能力 手搖飲店（50嵐、CoCo）、連鎖咖啡（星巴克、路易莎）
寡佔市場 少數幾家 同質或異質 相互依賴（策略互動） 四大超商（7-ELEVEN、全家促銷戰）

四、 辰鴻：Section 5.3 個別廠商供給、長期產業供給與彈性

1. 個別廠商短期供給曲線

完全競爭廠商追求利潤極大化，一階條件為 $P = MC$。當市場價格低於最低平均成本（長期）或最低平均變動成本（短期歇業點）時，廠商會停止生產。因此，個別廠商的供給曲線即為最低平均成本點以上的邊際成本（$MC$）上升段。

2. 自由進出與長期產業供給曲線

長期下廠商可自由進出市場，超額利潤會吸引新廠商進入、壓低價格，直到所有廠商經濟利潤歸零（$P = MC = \min AC$）。依據產業擴張對生產成本的影響，長期產業供給曲線分為三類：

  • 成本不變產業： 產業擴張不影響要素價格與外部性，長期供給曲線為水平線。
  • 成本遞增產業： 產業擴張引發負外部性或要素價格上漲（如漁場資源耗竭、土地租金飆升），長期供給曲線為正斜率。
  • 成本遞減產業： 產業群聚帶來正外部性或共用設備成本下降，長期供給曲線為負斜率。
  • 後彎型長期供給曲線（Backward-Bending）： 如海洋漁業，當魚價過高引發過度捕撈導致魚群資源枯竭時，價格再上升反而使總漁獲供給量減少。

3. 供給價格彈性（Price Elasticity of Supply, $E_s$）

$$\text{弧彈性：} E_s = \frac{(Q_B - Q_A)/Q_A}{(P_B - P_A)/P_A} = \frac{\Delta Q}{\Delta P} \cdot \frac{P_A}{Q_A}$$ $$\text{點彈性：} E_s = \frac{dQ}{dP} \cdot \frac{P}{Q}$$

完全無彈性（垂直供給線，如土地總量固定）$E_s = 0$；單位彈性 $E_s = 1$；富有彈性 $E_s > 1$；完全彈性（水平供給線）$E_s \to \infty$。

五、 裕芳 ＆ 晨熙：第5章 利潤極大化與長期均衡計算（5.1 ~ 5.6）

1. 裕芳：利潤極大化三步驟與實例檢驗（Exercises 5.1 & 5.2）

  1. 邊際條件求解： 令 $MC(Q) = P$ 求解候選產量。
  2. 二階條件與合理性篩選： 剔除負產量，並確認 $MC$ 處於上升階段。
  3. 歇業條件檢驗： 確認 $P \ge AC(Q)$（長期）或 $P \ge AVC(Q)$（短期），計算總利潤 $\pi = (P - AC) \times Q$。

例如 Exercise 5.1 中，$TC = Q^3 - 6Q^2 + 15Q$，$MC = 3Q^2 - 12Q + 15$。當 $P = 30$ 時，解得 $Q = 5$（剔除 $Q = -1$），此時 $AC(5) = 10 \le 30$，總利潤 $\pi = (30 - 10) \times 5 = 100$。

2. 晨熙：從短期超額利潤到長期競爭均衡（Exercises 5.5 & 5.6）

已知每家廠商的總成本與邊際成本函數為：

$$TC(Q) = Q^3 - 6Q^2 + 13Q \implies MC(Q) = 3Q^2 - 12Q + 13, \quad AC(Q) = Q^2 - 6Q + 13$$
  • 單一廠商短期決策（Exercise 5.5）： 當市場價格 $P = 13$ 時，令 $MC = 13 \implies 3Q^2 - 12Q = 0$，得 $Q = 0$（利潤極小點，$MC$ 遞減）或 $Q = 4$（利潤極大點，$MC$ 遞增）。在 $Q = 4$ 時，$AC(4) = 5$，單一廠商獲得超額利潤 $\pi = (13 - 5) \times 4 = 32$。
  • 長期自由進出均衡（Exercise 5.6）： 超額利潤吸引新廠商進入，價格一路下跌至最低平均成本處。令 $\frac{d\,AC}{dQ} = 2Q - 6 = 0 \implies Q^* = 3$，此時長期均衡價格 $P^* = \min AC = AC(3) = 4$，各廠商經濟利潤 $\pi = (4 - 4) \times 3 = 0$。
  • 產業總產量與均衡廠商數： 若市場總需求為 $P = 34 - 0.1Q_{\text{total}}$，代入 $P^* = 4$ 得產業總產量 $Q_{\text{total}} = 300$，因此市場容納的均衡廠商總家數為 $\frac{300}{3} = 100$ 家。
⚠️ 課堂共同提醒：AI 輔助研究與繪圖的驗證責任

在本次報告中，多位同學運用生成式 AI 協助繪製成本曲線與計算習題。池秉聰教授特別提醒研究生：

  • 切勿盲信 AI 輸出： AI 在處理數學函數微積分、反曲點或曲線交點（如 $MC$ 必須由下往上穿過 $AC$ 最低點）時，仍可能出現數值或幾何錯誤。
  • 建立獨立驗算習慣： 作為負責任的研究者，使用 AI 產出數據或圖表後，務必透過手算一階/二階條件或使用專業繪圖工具（如 Desmos）進行交叉驗證。
