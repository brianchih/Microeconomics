2.4 利潤極大化與供給函數 (Profit Maximization and Supply Functions)

指定教材：Burkett, J. P. (2006). Microeconomics: Optimization, Experiments, and Behavior. Oxford University Press.

章節範疇：Chapter 2: Inputs, Outputs, and Costs — Section 2.4

一、 本節理論精髓與 Burkett 的用心

在推導完生產函數（2.1 節）、成本最小化（2.2 節）與成本曲線（2.3 節）之後，John P. Burkett 在第 2.4 節將供給面的分析推向終點：企業利潤極大化行為與個人供給函數（Individual Supply Function）的導出。

Burkett 在本節呈現了個體經濟學極為核心的對偶結構（Duality）。他不僅展示了傳統價格接受者（Price Taker）廠商如何在邊際收益等於邊際成本（$MR = MC$）之處確定產量，更引述行為與實驗經濟學的結果，探討現實中管理者在面對價格波動、停業門檻與市場不確定性時，如何透過試錯與對偶原理（如霍特林引理 Hotelling's Lemma）導出具有理性基礎的供給反應。

二、 數理架構與供給函數導出

1. 利潤極大化的一階與二階條件

假設廠商面對產品市場價格 $p$，其總收益為 $R(q) = pq$，總成本函數為 $C(q)$。利潤極大化目標函數為：

$$\max_{q} \pi(q) = R(q) - C(q) = pq - C(q)$$

一階條件（First-Order Condition, FOC）：

$$\frac{d\pi}{dq} = p - \frac{dC}{dq} = 0 \implies p = MC(q)$$

二階條件（Second-Order Condition, SOC）：

$$\frac{d^2\pi}{dq^2} = -\frac{d^2C}{dq^2} < 0 \implies \frac{d(MC)}{dq} > 0$$

這說明極大化利潤的產量決策必須部位於邊際成本遞增的區段。

2. 短期供給曲線與停業點 (Shutdown Condition)

在短期內，廠商即使不生產也必須支付固定成本 $FC$。因此，只要市場價格高於平均可變成本（$p \ge SAVC$），繼續生產即可彌補部分固定成本；反之，若 $p < SAVC$，生產帶來的收益連變動成本都無法支應，廠商將選擇短期停業（$q = 0$）。

$$q^s(p) = \begin{cases} MC^{-1}(p), & \text{if } p \ge \min SAVC \\ 0, & \text{if } p < \min SAVC \end{cases}$$

3. 對偶性與霍特林引理 (Hotelling's Lemma)

定義極大化利潤函數為 $ \pi^*(p, w, r) = \max_{q} \{ pq - C(q, w, r) \} $。利用包絡線定理（Envelope Theorem），利潤函數對產品價格 $p$ 的偏微分即為廠商的個體供給函數：

$$\frac{\partial \pi^*(p, w, r)}{\partial p} = q^*(p, w, r)$$
💡 Burkett 的經濟直覺：霍特林引理的對偶美感

霍特林引理揭示了極其深厚的對偶性：不需要直接解微分方程，只要知道極大利潤函數 $\pi^*(p, w, r)$ 的形狀，對價格 $p$ 求一次導數就能精確得到供給函數 $q^*$！Burkett 提醒學生，這展現了個體理論在幾何與代數上的對稱與精簡之美。

三、 核心概念解析與真實世界時事案例

1. 邊際成本定價（$P = MC$）與高科技產業的價格談判

Burkett 強調，在競爭市場中，$P = MC$ 是資源配置達成 Pareto 最適的關鍵條件。然而在先進製造業中，邊際成本的計算高度依賴產品與製程的成熟度。

產業時事：晶圓代工（TSMC）與面板/記憶體景氣循環的定價策略

在半導體與顯示面板產業中，當市場供過於求、價格下跌時，廠商的產量調整策略充分驗證了 $P = MC$ 與停業點理論：

  • 成熟製程與舊廠： 廠房設備已完全折舊完畢，固定成本已沉沒，其 $SAVC$ 非常低。只要市場價格高於 $SAVC$，廠商就會維持投片生產（$q > 0$），導致景氣低谷時市場總供給依然堅挺。
  • 先進製程： 先進節點邊際成本高昂，當價格大幅回落時，廠商會透過降低產能利用率（減少 $q$）來維持價格高檔，確保利潤極大化條件 $MR = MC$ 成立。

2. 停業點（Shutdown Threshold）與農產品/能源市場決策

當市場價格跌破 $\min SAVC$ 時，理性廠商會選擇暫停營運而非盲目硬撐，這構成了供給曲線在低價區間的斷點。

生活實例：油價波動下頁岩油井的「封井與重啟」行為

美國頁岩油業者開採油井需要支付初期鑽探固定成本，而抽取石油則產生人工與化學品等可變成本（$VC$）。當國際原油價格暴跌至低於每桶頁岩油的邊際抽取成本（$SAVC$）時，業者會選擇封井停產（$q = 0$）。

一旦油價反彈超越停業點，業者能在極短時間內重啟採油。這使得頁岩油供給曲線在 $P = \min SAVC$ 處呈現高度彈性的邊際供給反應。以此案例，Burkett 的短期供給模型能精準預測真實能源市場的供給轉折點。

3. 政策補貼、碳稅與供給曲線的移位（Supply Shift）

當外生環境改變（如租稅、補貼或原料價格上漲）時，廠商的邊際成本曲線 $MC$ 會隨之移動，從而改變整條供給曲線。

前沿應用：綠能補貼與電動車碳稅對市場供給的塑造

政府施加碳稅相當於提高每單位產出的邊際成本（$MC' = MC + t$），導致廠商供給曲線向左上方移動，在相同價格下減少供給量；反之，綠能或電動車生產補貼（$s$）降低了邊際成本（$MC' = MC - s$），促使供給曲線向右下方移動，擴大市場供給規模。

運用霍特林引理 $\frac{\partial \pi^*}{\partial p} = q^*$，我們可以方便地評估碳稅或補貼政策對整體產業總利潤與總供給量的敏感度分析（Comparative Statics）。

四、 碩士班深度思考與討論議題

💬 課堂研討題目 (Classroom Discussion)
  1. 行為經濟學與目標利潤偏誤： 理論假設廠商目標是追求「利潤極大化」（Profit Maximization）。但 Herbert Simon 指出，真實經理人往往追求「滿意利潤」（Satisficing Behavior）。在實驗經濟學中，當經理人達成預設業績目標後，其供給反應會如何偏離 $P = MC$ 的預測？
  2. 市場結構與邊際收益（MR）： 2.4 節主要聚焦於價格接受者（$P = MR = MC$）。若廠商具備市場能力（Market Power，如獨占或寡占），其邊際收益 $MR = P(1 + \frac{1}{\epsilon})$ 小於價格 $P$，這對廠商供給曲線的存在性（Existence of Supply Curve）產生了何種理論挑戰？
  3. 代理人模型 (ABM) 中的動態供給湧現： 在一個包含數百家異質廠商（成本結構不同、資訊不完全）的 ABM 市場中，如果廠商僅能透過觀察上一期市場價格來調整本期產量（如 Cobweb Model 蛛網模型），個體廠商的利潤極大化嘗試會如何引發整體市場供給量的震盪與收斂？
