1. 問題一：CES 生產函數與替代彈性推導

📌 Problem 2.6.1：常數替代彈性 (CES) 函數的拉格朗日求解

假設某先進科技製造廠的生產函數為 CES 形式：

$$q = A \left[ \alpha K^{-\rho} + (1-\alpha) L^{-\rho} \right]^{-\frac{1}{\rho}} \quad (\text{其中 } A > 0, 0 < \alpha < 1, \rho > -1, \rho \neq 0)$$

要素價格分別為工資率 $w$ 與資本租金 $r$，目標產量為 $q_0$。

(a) 利用拉格朗日乘數法求解極小化成本問題，推導資本與勞動的最佳投入比例 $\frac{K}{L}$。
(b) 證明其替代彈性 $\sigma = \frac{1}{1+\rho}$。

💡 解析指引與步驟拆解

(a) 拉格朗日一階條件求解：

建立拉格朗日函數 $\mathcal{L} = wL + rK + \lambda \left( q_0 - A [ \alpha K^{-\rho} + (1-\alpha) L^{-\rho} ]^{-\frac{1}{\rho}} \right)$。

求 $L$ 與 $K$ 的偏微分並令其為零，計算邊際技術替代率：

$$MRTS_{L,K} = \frac{MP_L}{MP_K} = \frac{1-\alpha}{\alpha} \left( \frac{K}{L} \right)^{\rho + 1} = \frac{w}{r}$$

重組後即可獲得最適要素比例 $\frac{K}{L}$：

$$\frac{K}{L} = \left( \frac{\alpha}{1-\alpha} \cdot \frac{w}{r} \right)^{\frac{1}{1+\rho}}$$

(b) 證明替代彈性 $\sigma$：

對最適要素比例兩邊取自然對數：

$$\ln\left(\frac{K}{L}\right) = \frac{1}{1+\rho} \ln\left(\frac{\alpha}{1-\alpha}\right) + \frac{1}{1+\rho} \ln\left(\frac{w}{r}\right)$$

根據替代彈性定義 $\sigma = \frac{\partial \ln(K/L)}{\partial \ln(w/r)}$，可得 $\sigma = \frac{1}{1+\rho}$，證畢。

2. 問題二：謝法德引理 (Shephard's Lemma) 證明題

📌 Problem 2.6.2：總成本函數與條件要素需求的偶對關係

假設廠商的總成本函數為 $C(w, r, q_0)$，該函數由成本極小化問題推導而得。請利用包絡線定理（Envelope Theorem）證明謝法德引理：

$$\frac{\partial C(w, r, q_0)}{\partial w} = L^c(w, r, q_0) \quad \text{且} \quad \frac{\partial C(w, r, q_0)}{\partial r} = K^c(w, r, q_0)$$

💡 解析指引與步驟拆解

根據定義，極小化問題對應的目標拉格朗日函數在極值點上的數值等於總成本：

$$C(w, r, q_0) = \mathcal{L}^*(w, r, q_0) = w L^c + r K^c + \lambda \left( q_0 - f(K^c, L^c) \right)$$

根據包絡線定理，當參數 $w$ 發生微小變動時，要素調整對約束條件的間接效應在一階條件下消失，因此可以無視 $L^c, K^c, \lambda$ 對 $w$ 的隱函數偏微分：

$$\frac{\partial C(w, r, q_0)}{\partial w} = \frac{\partial \mathcal{L}^*}{\partial w} = L^c(w, r, q_0)$$

同理對 $r$ 偏微分亦可得 $K^c(w, r, q_0)$。這項性質在實證計量經濟學中極為重要，讓研究者無需直接觀察生產函數，即可透過成本函數估計出條件要素需求。

3. 產業時事對照：碳費徵收與綠電轉型的成本優化演練

📰 產業時事：ESG 與綠電加價下的科技業多要素成本極小化

背景對照： 在 Problem 2.6.1 的 CES 函數模型中，當要素價格發生結構性轉變（例如碳費開徵導致高碳傳統能源價格 $p_{fossil}$ 上漲），企業必須調整要素比例。

許多半導體與高科技製造業正積極進行「能源要素替代」：

  • 企業透過簽署長期綠電採購合約（CPPA）或建置自發自用太陽能儲能設備（增加資本 $K$），來降低對傳統排碳電力（$E$）的依賴。
  • 這正是利用 Problem 2.6.1 推導出來的替代彈性公式 $\sigma = \frac{\partial \ln(K/E)}{\partial \ln(p_{fossil}/r)}$ 進行長期的資本與能源結構重組。

4. 生活案例：碩士生的時間配置與多任務最適化

🎓 生活案例：學術論文、實習實戰與休息放鬆的影子價格

情境對照： Problem 2.6.2 中的包絡線定理與拉格朗日乘數 $\lambda$ 展現了資源約束下「影子價格」的概念。

碩士生在撰寫畢業論文時，時間總量 $T$ 屬於硬性約束：

  • 若論文審查期限逼近（約束條件 $q_0$ 提高），時間的影子價格 $\lambda$（每增加一頁論文所消耗的睡眠與精神價值）會急劇上升。
  • 理解這個優化模型有助於碩士生建立時間管理策略：在早期（$\lambda$ 較低時）適當增加資本投入（例如學習自動化排版與數據分析工具），降低後期的邊際時間成本。

5. 課後自主練習題目 (Self-Challenge Exercises)

請各位同學嘗試獨立完成以下進階章末練習：

  1. 規模報酬與成本函數關係： 假設生產函數具備 $t$ 階齊次性（Homogeneous of degree $t$），即 $f(kK, kL) = k^t f(K,L)$。請證明其總成本函數可以寫成： $$C(w, r, q_0) = q_0^{\frac{1}{t}} \cdot C(w, r, 1)$$ 並說明當 $t > 1$（規模報酬遞增）時，邊際成本 $MC$ 隨產量變化的趨勢。
  2. 柯布-道格拉斯生產函數的短長期成本對比： 設 $q = K^{0.5} L^{0.5}$，短期內資本固定於 $\bar{K}$。請推導短期總成本函數 $STC(w, r, q, \bar{K})$，並證明當 $\bar{K}$ 等於長期最適資本需求 $K^c$ 時，短期邊際成本等於長期邊際成本。
