2.2 要素替代 (Input Substitution)

John P. Burkett《Microeconomics: Optimization, Experiments, and Behavior》第二章專題

本節導讀：技術彈性與生產結構調整

在 2.1 節中，我們建立了投入、產出與成本的基本概念。本節（2.2 要素替代）進一步探討：當相對要素價格（例如工資率與資本租金的比率 $w/r$）改變時，廠商如何在保持總產出 $q$ 不變的前提下，靈活調整資本 $K$ 與勞動 $L$ 的組合。

這不僅是數學上的隱函數與彈性計算，更是企業面對 AI 自動化浪潮、勞力短缺與碳費等外部衝擊時，評估轉型空間的重要工具。

1. 等產量曲線與邊際技術替代率 (MRTS)

給定生產函數 $q = f(K, L) = \bar{q}$，沿著同一條等產量曲線進行全微分：

$$dq = \frac{\partial f}{\partial L} dL + \frac{\partial f}{\partial K} dK = 0$$

由此可推導出邊際技術替代率（Marginal Rate of Technical Substitution, $MRTS$）：

$$MRTS_{L,K} = -\frac{dK}{dL}\bigg|_{q=\bar{q}} = \frac{MP_L}{MP_K}$$

Burkett 教授強調，因邊際報酬遞減法則，典型的等產量曲線呈現向原點凸出（Convex to the origin）的幾何形狀，代表 $MRTS_{L,K}$ 隨勞動投入 $L$ 的增加而遞減。

2. 替代彈性 ($\sigma$)：衡量替代的難易程度

$MRTS$ 描述了替代的「邊際變動率」，而替代彈性 ($\sigma$) 則是衡量要素間互相替代「難易程度」的無單位指標。

數學定義

替代彈性 $\sigma$ 定義為「要素比例 ($K/L$) 的百分比變動」與「邊際技術替代率 ($MRTS$) 的百分比變動」之比值：

$$\sigma = \frac{\% \Delta (K/L)}{\% \Delta MRTS_{L,K}} = \frac{d(K/L) / (K/L)}{d(MRTS) / MRTS} = \frac{\partial \ln(K/L)}{\partial \ln(MRTS)}$$

在成本極小化條件下，$MRTS = \frac{w}{r}$，因此 $\sigma$ 亦可表示為要素比例對相對要素價格變動的敏感度：

$$\sigma = \frac{\partial \ln(K/L)}{\partial \ln(w/r)}$$

常見生產函數類型與其替代彈性對比

1. 完全替代型 (Linear)

$$q = aL + bK$$

替代彈性： $\sigma = \infty$

要素間可完全無縫轉換（例如雲端運算算力與自建實體伺服器）。

2. 里昂提夫型 (Leontief)

$$q = \min(aL, bK)$$

替代彈性： $\sigma = 0$

要素按固定比例搭配，無法相互替代（例如一輛公車配置一名司機）。

3. 柯布-道格拉斯型 (Cobb-Douglas)

$$q = A K^\alpha L^\beta$$

替代彈性： $\sigma = 1$ （恆等於 1）

相對要素價格波動時，要素支出占總成本之比重保持常數。

4. CES 型 (Constant Elasticity)

$$q = A [\alpha K^{-\rho} + (1-\alpha)L^{-\rho}]^{-\frac{1}{\rho}}$$

替代彈性： $\sigma = \frac{1}{1+\rho}$

一般化的生產函數，能更真實地涵蓋各種產業經驗值。

3. 產業時事：生成式 AI 狂潮與白領勞動的要素替代

📰 全球科技產業：生成式 AI 自動化與軟體工程人力調配

背景新聞： 全球高科技公司與金融機構相繼導入生成式 AI 與 Coding Agent（如 GitHub Copilot），調整初級程式設計師與審核人員的組織規模，同時大幅增加 GPU 算力集群投資。

個體經濟學解析：

  • 相對價格變動 ($\Delta \frac{w}{r}$)： 軟體研發與合規審查的人力成本（$w$）居高不下，而 AI 算力的單位成本（$r$）相對降低，導致相對價格比率 $w/r$ 上升。
  • 替代彈性效應 ($\sigma > 0$)： 在寫程式與客服領域，生產函數展現較高的替代彈性。企業藉由提高 $K/L$ 比例（即每位工程師配置多個 AI Agent 助手），在維持產出 $q$ 的前提下達到成本壓低效果。

4. 生活案例：連鎖餐飲與點餐系統升級

🍜 身邊案例：連鎖拉麵店的點餐機與 QR Code 點餐

生活體驗： 走進現代拉麵店，過往需要 2 位外場員工負責介紹菜單與點餐，現在顧客自行掃碼或使用平板點餐，外場僅需 1 位員工進行端湯與清潔。

經濟學模型化思考：

  • 短期（Short-run）： 點餐設備屬於固定資本 $K$。導入點餐系統後，「記單與點餐」功能展現出極高的替代性（局部 $\sigma \to \infty$）。
  • 不可替代的邊界： 端熱湯與清理桌面等實體服務，目前機器人技術成本仍過高（$r_{robot}$ 極高），這部分生產函數接近 Leontief 型態（$\sigma \to 0$），仍需保留基本勞動 $L$。
