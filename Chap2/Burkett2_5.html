本節導讀：從數學演算到商業邏輯的驗證

在第 2.1 至 2.3 節中，我們研討了個體經濟學中有關投入、產出與成本極小化的理論架構。本節（2.5 節）針對教材內文的隨堂練習（Exercises）提供嚴密的解答與數學推導步驟。

對碩士生而言，掌握這些數學推導不僅能提升微積分優化的工具應用能力，更能深刻理解演算成果如何對應到現實世界中企業的成本極小化策略。

1. 練習 2.1 解答：邊際產量與邊際技術替代率推導

📝 題目 2.1 (Exercise 2.1)

假設某廠商的生產函數為柯布-道格拉斯（Cobb-Douglas）形式：

$$q = A K^\alpha L^\beta \quad (\text{其中 } A > 0, 0 < \alpha < 1, 0 < \beta < 1)$$

(a) 求勞動邊際產量 ($MP_L$) 與資本邊際產量 ($MP_K$)。
(b) 推導邊際技術替代率 ($MRTS_{L,K}$)，並說明其是否隨著 $L$ 的增加而遞減？

詳細解答與推導步驟

(a) 計算邊際產量：

分別對偏微分：

$$MP_L = \frac{\partial q}{\partial L} = \beta A K^\alpha L^{\beta - 1} = \beta \frac{q}{L}$$
$$MP_K = \frac{\partial q}{\partial K} = \alpha A K^{\alpha - 1} L^\beta = \alpha \frac{q}{K}$$

(b) 計算與分析 $MRTS_{L,K}$：

根據邊際技術替代率定義：

$$MRTS_{L,K} = \frac{MP_L}{MP_K} = \frac{\beta \frac{q}{L}}{\alpha \frac{q}{K}} = \left(\frac{\beta}{\alpha}\right) \cdot \left(\frac{K}{L}\right)$$

當產量固定在 $q = \bar{q}$ 時，沿著等產量曲線增加勞動 $L$，資本 $K$ 必須減少。因此，要素比例 $\frac{K}{L}$ 會隨著 $L$ 的增加而下降。由於 $\frac{\beta}{\alpha} > 0$，這證明了 $MRTS_{L,K}$ 隨著 $L$ 的增加而遞減（等產量曲線呈現向原點凸出）。

2. 練習 2.2 解答：拉格朗日法求解成本極小化

📝 題目 2.2 (Exercise 2.2)

承接題目 2.1 的生產函數 $q = A K^\alpha L^\beta$，給定工資率 $w$ 與資本租金 $r$，目標產量為 $q_0$。

(a) 建立拉格朗日函數，求條件要素需求函數 $L^c(w,r,q_0)$ 與 $K^c(w,r,q_0)$。
(b) 求總成本函數 $C(w,r,q_0)$，並說明拉格朗日乘數 $\lambda$ 的意義。

詳細解答與推導步驟

(a) 拉格朗日極小化：

建構目標函數：

$$\mathcal{L}(K, L, \lambda) = wL + rK + \lambda \left( q_0 - A K^\alpha L^\beta \right)$$

求一階條件 (FOCs)：

$$\begin{aligned} \frac{\partial \mathcal{L}}{\partial L} &= w - \lambda \beta A K^\alpha L^{\beta-1} = 0 \implies w = \lambda MP_L \\[6pt] \frac{\partial \mathcal{L}}{\partial K} &= r - \lambda \alpha A K^{\alpha-1} L^\beta = 0 \implies r = \lambda MP_K \\[6pt] \frac{\partial \mathcal{L}}{\partial \lambda} &= q_0 - A K^\alpha L^\beta = 0 \end{aligned}$$

前兩式相除得均衡相對投入比例：

$$\frac{w}{r} = \frac{\beta K}{\alpha L} \implies K = \left(\frac{\alpha}{\beta}\right) \left(\frac{w}{r}\right) L$$

將 $K$ 帶入產能限制條件 $q_0 = A K^\alpha L^\beta$ 中求解，可得條件要素需求：

$$L^c(w, r, q_0) = \left( \frac{q_0}{A} \right)^{\frac{1}{\alpha+\beta}} \left( \frac{\beta w}{\alpha r} \right)^{-\frac{\alpha}{\alpha+\beta}}$$
$$K^c(w, r, q_0) = \left( \frac{q_0}{A} \right)^{\frac{1}{\alpha+\beta}} \left( \frac{\alpha r}{\beta w} \right)^{-\frac{\beta}{\alpha+\beta}}$$

(b) 總成本函數與 $\lambda$ 意義：

將 $L^c$ 與 $K^c$ 帶入 $C = wL^c + rK^c$，可推導出成本函數：

$$C(w, r, q_0) = \left( \frac{q_0}{A} \right)^{\frac{1}{\alpha+\beta}} \left[ \left(\frac{\alpha}{\beta}\right)^{\frac{\beta}{\alpha+\beta}} + \left(\frac{\beta}{\alpha}\right)^{\frac{\alpha}{\alpha+\beta}} \right] w^{\frac{\beta}{\alpha+\beta}} r^{\frac{\alpha}{\alpha+\beta}}$$

拉格朗日乘數 $\lambda = \frac{\partial C}{\partial q_0} = MC$，代表多生產一單位產出所增加的最小邊際成本負擔。

3. 產業時事對照：習題解答在科技產業成本調配的現實意義

📰 產業時事：Meta 與 Google 的 AI 資料中心電力與算力優化（解題公式的現實落實）

背景對照： 在題目 2.2 推導出來的條件要素需求公式中，$L^c$ 與 $K^c$ 取決於相對要素價格比率 $\frac{w}{r}$。

現實中，科技巨頭在建設生成式 AI 訓練基礎設施時，面臨電力（$E$）與高端 GPU 伺服器（$K$）的選擇：

  • 當某些地區電力價格（$p_e$）暴漲時，公式顯示 $K^c/E^c$ 的比例會隨相對價格上升而重新調整。
  • 企業會選擇將 AI 模型「預訓練（Pre-training）」移至電費低廉的地方，而將對延遲敏感的「推理（Inference）」留在都市邊緣，這正是利用推導出來的最小成本函數 $C(w,r,q_0)$ 進行全球資源最適化配置。

4. 生活案例：研究生期末複習與報告準備的微積分體驗

🎓 生活案例：課業、論文與實習申請的均衡回報

情境對照： 練習題 2.2 中的一階條件 $\frac{MP_L}{w} = \frac{MP_K}{r} = \frac{1}{\lambda}$ 說明了「均等邊際效益原則」。

研究生在期末考週面臨多門高級課程（例如個體經濟學與計量經濟學）：

  • 若你在個體經濟學上多花 1 小時能讓總分提升 5 分，但在計量經濟學上多花 1 小時能讓總分提升 10 分，這代表你的資源（時間）分配尚未達到最適。
  • 你應該轉移時間至計量經濟學，直到每小時帶來的邊際分數增加量相等為止。此時的影子價格 $\lambda$ 就是你獲得更高的 GPA 所付出的時間邊際成本。

5. 碩士班進階演練 (Self-Practice Challenge)

請各位同學嘗試獨立推導以下延伸題目：

  1. Leontief 生產函數： 若生產函數為 $q = \min(2L, 3K)$，要素價格為 $w=10, r=15$。請繪製其等產量曲線，並求出生產 $q_0 = 60$ 時的最小成本與條件要素需求 $L^c, K^c$。（提示：思考為何拉格朗日法在此處無法直接微分？）
  2. 謝法德引理（Shephard's Lemma）驗證： 利用練習 2.2 推導出的總成本函數 $C(w, r, q_0)$，求偏導數 $\frac{\partial C}{\partial w}$，並驗證其是否精確等於 $L^c(w, r, q_0)$。
