        <div class="space-y-6">
          <!-- 1.1 Core Definition & Shovel Intuition -->
          <div class="grid grid-cols-1 lg:grid-cols-12 gap-4">
            <div class="lg:col-span-7 bg-slate-50 rounded-xl p-5 border border-slate-200">
              <h3 class="font-bold text-slate-900 text-base mb-2">1. 邊際產量定義與邊際報酬遞減法則</h3>
              <p class="text-sm text-slate-700 leading-relaxed mb-3">
                在維持其他生產要素投入量固定不變（<em>ceteris paribus</em>）的前提下，額外增加一單位某一特定生產要素所帶來的總產出增量，稱為該要素的<strong>邊際產量（Marginal Product）</strong>：
              </p>
              <div class="grid grid-cols-1 sm:grid-cols-2 gap-3 my-2">
                <div class="bg-white p-3 rounded-lg border border-slate-200 text-center">
                  <span class="text-xs text-slate-500 block">勞動邊際產量（$MP_L$）</span>
                  $$MP_L = \frac{\partial Q(K, L)}{\partial L}$$
                </div>
                <div class="bg-white p-3 rounded-lg border border-slate-200 text-center">
                  <span class="text-xs text-slate-500 block">資本邊際產量（$MP_K$）</span>
                  $$MP_K = \frac{\partial Q(K, L)}{\partial K}$$
                </div>
              </div>
              <p class="text-xs text-slate-600 mt-2 leading-relaxed">
                <strong>邊際報酬遞減（Diminishing Marginal Returns）：</strong>當其他要素固定而持續增加某一要素時，初期可能因專業分工使邊際產量上升，但超過特定臨界點後，新增要素所帶來的額外產出貢獻終將遞減，甚至趨近於零或轉為負值。
              </p>
            </div>

            <!-- Shovel Analogy & Jensen Huang Current Event -->
            <div class="lg:col-span-5 bg-amber-50/70 rounded-xl p-5 border border-amber-200 flex flex-col justify-between">
              <div>
                <div class="flex items-center gap-2 mb-2">
                  <span class="text-lg">⛏️</span>
                  <h3 class="font-bold text-amber-950 text-base">經典直覺：「挖水溝與鏟子」與 AI 時事連結</h3>
                </div>
                <p class="text-xs sm:text-sm text-amber-950/90 leading-relaxed mb-2.5">
                  <strong>課本經典比喻：</strong>假設固定有 2 名工人挖水溝，第 1 把鏟子讓產出開始增加；第 2 把鏟子讓兩人同時開挖、分工協作，產出大幅躍升；但若再增加<strong>第 3 把鏟子</strong>（人力固定為 2 人），多出的鏟子完全派不上用場，$MP_K$ 驟降為 0！
                </p>
              </div>
              <div class="bg-white/90 rounded-lg p-3 border border-amber-200/80 text-xs text-slate-700 leading-relaxed">

              </div>
            </div>
          </div>

          <!-- 1.2 Two Production Function Shapes Comparison -->
          <div>
            <h3 class="font-bold text-slate-900 text-base mb-3">2. 兩種生產函數型態與邊際產量曲線的幾何對照</h3>
            <div class="grid grid-cols-1 md:grid-cols-2 gap-4">
              <!-- Type A: Cobb-Douglas -->
              <div class="rounded-xl border border-slate-200 p-5 bg-white">
                <div class="flex items-center justify-between mb-2">
                  <span class="font-bold text-blue-900 text-base">型態 A：Cobb-Douglas 生產函數</span>
                  <span class="text-xs font-mono bg-blue-50 text-blue-700 px-2 py-0.5 rounded">單調遞減 • 凸向原點</span>
                </div>
                <div class="bg-slate-50 p-3 rounded-lg border border-slate-200/80 text-center my-2 text-sm">
                  $$Q = A K^\alpha L^\beta \implies MP_K = \alpha A K^{\alpha-1} L^\beta, \quad MP_L = \beta A K^\alpha L^{\beta-1}$$
                </div>
                <ul class="text-xs sm:text-sm text-slate-700 space-y-1.5 leading-relaxed mt-2">
                  <li>• <strong>單調遞減與凸性：</strong>當 $0 < \alpha, \beta < 1$ 時，一階偏導數隨該要素增加而一路下滑（由陡峭轉為平緩，曲線凸向原點），反映邊際技術替代率遞減（$MRTS$ 遞減）。</li>
                  <li>• <strong>規模報酬固定（CRS, $\alpha + \beta = 1$）的重要性質：</strong>此時 $Q = A K^\alpha L^{1-\alpha}$，邊際產量可改寫為僅取決於<strong>資本勞動比（$K/L$）</strong>的函數：
                    $$MP_K = \alpha A \left(\frac{K}{L}\right)^{\alpha - 1}, \quad MP_L = (1-\alpha) A \left(\frac{K}{L}\right)^{\alpha}$$
                    代表只要 $K$ 與 $L$ 維持<strong>同比例擴張</strong>，$MP_K$ 與 $MP_L$ 皆完全保持不變！
                  </li>
                </ul>
              </div>

              <!-- Type B: S-Shaped Production Function -->
              <div class="rounded-xl border border-slate-200 p-5 bg-white">
                <div class="flex items-center justify-between mb-2">
                  <span class="font-bold text-emerald-900 text-base">型態 B：先遞增後遞減的 S 型生產函數</span>
                  <span class="text-xs font-mono bg-emerald-50 text-emerald-700 px-2 py-0.5 rounded">倒 U 型邊際產量</span>
                </div>
                <p class="text-xs sm:text-sm text-slate-700 leading-relaxed mb-2">
                  當固定資本與空間不變，勞動投入由極少逐步增加時，總產量線呈現先凸後凹的 <strong>S 型（Sigmoid-like）</strong>，對應的 $MP_L$ 則呈現先升後降的<strong>倒 U 型</strong>：
                </p>
                <div class="space-y-2 text-xs sm:text-sm">
                  <div class="p-2.5 rounded-lg bg-emerald-50/60 border border-emerald-200/70">
                    <strong class="text-emerald-950">階段一（邊際產量遞增階段）：</strong>初期人手不足，新增勞動力能透過分工協作大幅提升效率，總產量曲線斜率越來越陡峭，$MP_L$ 一路攀升。
                  </div>
                  <div class="p-2.5 rounded-lg bg-slate-50 border border-slate-200">
                    <strong class="text-slate-900">反曲點（Inflection Point）：</strong>滿足 $\frac{\partial MP_L}{\partial L} = \frac{\partial^2 Q}{\partial L^2} = 0$，此時總產量線斜率最陡，<strong>$MP_L$ 達到最高峰</strong>。
                  </div>
                  <div class="p-2.5 rounded-lg bg-amber-50/60 border border-amber-200/70">
                    <strong class="text-amber-950">階段二（邊際產量遞減階段）：</strong>跨越反曲點後，受限於固定空間與設備擁擠，總產量雖仍增加但增速趨緩（斜率轉平），$MP_L$ 開始持續下滑。
                  </div>
                </div>
              </div>
            </div>
          </div>

            <h3 class="font-bold text-slate-900 text-base mb-2">1. 要素雇用決策與一階最適條件（$VMP_L = w, VMP_K = r$）</h3>
            <p class="text-sm text-slate-700 leading-relaxed mb-3">
              在產品市場與要素市場皆為價格接受者（給定產品單價 $P$、工資率 $w$、資本租金率 $r$）下，企業選擇資本 $K$ 與勞動 $L$ 以極大化總利潤：
            </p>
            <div class="bg-white p-3.5 rounded-xl border border-slate-200 text-center my-2 overflow-x-auto">
              $$\max_{K, L} \ \pi(K, L) = P \cdot Q(K, L) - r K - w L$$
            </div>
            <div class="grid grid-cols-1 md:grid-cols-2 gap-4 mt-3 text-sm">
              <div class="bg-white p-4 rounded-xl border border-slate-200">
                <div class="font-bold text-blue-900 mb-1">勞動最適雇用一階條件（FOC for $L$）</div>
                <div class="my-1.5 text-center">$$\frac{\partial \pi}{\partial L} = P \cdot MP_L - w = 0 \implies VMP_L \equiv P \cdot MP_L = w$$</div>
                <ul class="text-xs text-slate-600 space-y-1 mt-2">
                  <li>• 若 $VMP_L > w$：多雇一單位勞工帶來的邊際產值高於工資，應<strong>增聘勞工</strong>以擴大總利潤。</li>
                  <li>• 若 $VMP_L < w$：邊際產值低於工資，多雇反而虧損，應<strong>縮減人力</strong>。</li>
                </ul>
              </div>
              <div class="bg-white p-4 rounded-xl border border-slate-200">
                <div class="font-bold text-emerald-900 mb-1">資本最適雇用一階條件（FOC for $K$）</div>
                <div class="my-1.5 text-center">$$\frac{\partial \pi}{\partial K} = P \cdot MP_K - r = 0 \implies VMP_K \equiv P \cdot MP_K = r$$</div>
                <ul class="text-xs text-slate-600 space-y-1 mt-2">
                  <li>• <strong>二階條件（SOC）：</strong>必須確保邊際產量遞減（$\frac{\partial^2 Q}{\partial L^2} < 0, \frac{\partial^2 Q}{\partial K^2} < 0$），即沿著向下傾斜的 $VMP$ 曲線決策。</li>
                </ul>
              </div>
            </div>

              <strong class="text-blue-950">🔍 關鍵觀念釐清：「邊際條件 $VMP_L = w$ 成立」$\neq$「企業總利潤為零」！</strong>
              <p class="mt-1 leading-relaxed text-slate-700">
                以課堂算例驗證：設固定資本下短期生產函數為 $Q = 12L - 0.5L^2$，產品單價 $P = 10$，工資 $w = 60$，固定設備成本 $FC = 100$。
                由 $VMP_L = 10(12 - L) = 60$ 解得最適雇用量 <strong>$L^* = 6$</strong>，此時總產量 $Q^* = 12(6) - 0.5(36) = \mathbf{54}$。
                計算總收益 $TR = 10 \times 54 = \mathbf{540}$，勞動總成本 $wL^* = 60 \times 6 = \mathbf{360}$，扣除固定成本 $100$ 後，企業總利潤仍高達：
                $$\pi = 540 - 360 - 100 = \mathbf{80\text{ 元}} > 0$$
              </p>

      if (!model) return;

      [1, 2, 3, 4].forEach(id => {
        const btn = document.getElementById(`btn-model-${id}`);
        if (id === modelId) {
          btn.className = "model-tab text-left px-3.5 py-3 rounded-xl border transition flex flex-col justify-between bg-blue-600 border-blue-400 text-white shadow";
        } else {
          btn.className = "model-tab text-left px-3.5 py-3 rounded-xl border transition flex flex-col justify-between bg-slate-800/90 border-slate-700 text-slate-200 hover:bg-slate-700";
        }
      });

      document.getElementById('guide-title').textContent = model.title;
      document.getElementById('guide-content').innerHTML = model.guideHTML;
      document.getElementById('guide-equations').textContent = model.copyText;
      currentEquationsText = model.copyText;

      if (calculator) {
        calculator.setBlank();
        calculator.setMathBounds(model.viewport);
        model.expressions.forEach(expr => {
          calculator.setExpression(expr);
        });
      }
    }

    // Copy equations list to clipboard (iframe-safe)
    function copyEquationsList() {
      const textarea = document.createElement('textarea');
      textarea.value = currentEquationsText;
      textarea.style.position = 'fixed';
      textarea.style.opacity = '0';
      document.body.appendChild(textarea);
      textarea.select();
      try {
        document.execCommand('copy');
        const btn = document.getElementById('copy-eq-btn');
        const orig = btn.textContent;
        btn.textContent = '已複製！';
        btn.classList.replace('bg-blue-600', 'bg-emerald-600');
        setTimeout(() => {
          btn.textContent = orig;
          btn.classList.replace('bg-emerald-600', 'bg-blue-600');
        }, 2000);
      } catch (err) {
        console.error('Copy failed', err);
      }
      document.body.removeChild(textarea);
    }

    // Download standalone HTML file
    function downloadSelfHTML() {
      const htmlContent = "<!DOCTYPE html>\n" + document.documentElement.outerHTML;
      const blob = new Blob([htmlContent], { type: 'text/html;charset=utf-8' });
      const url = URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url;
      a.download = '碩士班個體經濟理論導讀_Ch6_邊際產量與邊際要素需求_Desmos互動教材.html';
      document.body.appendChild(a);
      a.click();
      document.body.removeChild(a);
      URL.revokeObjectURL(url);
    }
