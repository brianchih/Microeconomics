第二部分：教科書第二章——生產要素與成本極小化

1. 基本概念與生產函數 ($2.1$)

生產是將投入資源轉換為產出的過程。定義勞動為 $L$、資本為 $K$、中間原料為 $M$，產出為 $Q$：

$$\text{一般生產函數：} Q = f(L, K)$$ $$\text{柯布-道格拉斯 (Cobb-Douglas) 生產函數：} Q = A L^{\alpha} K^{\beta}$$

對數線性化 (Log-Linearization)： 取對數後可將非線性關係轉化為線性迴歸模型：

$$\ln Q = \ln A + \alpha \ln L + \beta \ln K$$

2. 等產量線與等成本線 ($2.2 - 2.4$)

  • 等產量線 (Isoquant)： 代表在給定產量 $\bar{Q}$ 下，所有可能的投入要素組合。其斜率的絕對值為邊際技術替代率 (MRTS)： $$MRTS_{LK} = -\frac{dK}{dL} = \frac{MP_L}{MP_K}$$
  • 等成本線 (Isocost)： 給定總成本 $C$、工資率 $w$（或 $P_L$）與資本價格 $r$（或 $P_K$）： $$C = wL + rK \implies K = \frac{C}{r} - \left(\frac{w}{r}\right)L$$

3. 最適化：成本極小化條件 ($2.2.2 - 2.4$)

廠商的目標是在給定目標產量 $\bar{Q}$ 下追求總成本最小化：

$$\min_{L,K} \; wL + rK \quad \text{s.t.} \quad f(L,K) = \bar{Q}$$ $$\text{建立拉格朗日函數 (Lagrangian)：} \mathcal{L}(L, K, \lambda) = wL + rK + \lambda \left[\bar{Q} - f(L,K)\right]$$

一階最適條件 (FOCC)：

  1. 內部解 (Interior Solution)： 當等產量線與等成本線相切於第一象限內時： $$MRTS_{LK} = \frac{MP_L}{MP_K} = \frac{w}{r} \implies \frac{MP_L}{w} = \frac{MP_K}{r}$$ 直覺解釋：每一單位貨幣花費在勞動上的邊際產量，必須等於花費在資本上的邊際產量。
  2. 角解 (Corner Solution)： 若兩要素為完全替代或某要素價格過高，最適點落在座標軸上（只選用單一要素）。

第三部分：課堂習題精選與詳細推導 ($2.6$)

習題 1：閣樓草藥種植案例

已知條件：

  • 生產函數：$Q = 3 K^{0.5} L^{0.5}$，目標附加價值 $Q = 18,000$。
  • 資本租用成本 $r = 0.20$，勞動機會成本 $w = 7.2$ 美元/小時。
  • 等產量線斜率絕對值為 $\frac{K}{L}$。

求解與推導：

  1. 求解最適投入量 $(K^*, L^*)$：

    根據切點條件 $MRTS = \frac{w}{r}$：

    $$\frac{K}{L} = \frac{7.2}{0.20} = 36 \implies K = 36L$$

    代回生產函數求解 $L$：

    $$18,000 = 3 (36L)^{0.5} L^{0.5} = 3 \times 6 \times L = 18L \implies L^* = 1,000 \text{ 小時}$$

    代回求 $K$：

    $$K^* = 36 \times 1,000 = 36,000 \text{ 美元}$$
  2. 獲利評估： $$\text{總經濟成本 } TC = (0.20 \times 36,000) + (7.2 \times 1,000) = 7,200 + 7,200 = 14,400 \text{ 美元}$$ $$\text{經濟利潤 } \pi = \text{淨收益 } Q - TC = 18,000 - 14,400 = 3,600 \text{ 美元}$$

    結論：可獲得 3,600 美元 之純利潤，該方案可以獲利。

習題 2：看門狗最佳飲食配方

已知條件：

  • 大腸量為 $C$，鯊魚肉量為 $S$。大腸單價 $P_C = 1$ 美元，鯊魚肉單價 $P_S = 4$ 美元。
  • 等成本線為 $4S + C = C_{ost}$，斜率絕對值為 $4$。

求解與判斷：

  1. 計算可得切點對應之 $S \approx -0.26$。由於投入量不得為負數 ($S \ge 0$)，顯示切點不在可行域（第一象限）內，故不存在內部解。
  2. 端點（角解）比較：
    • 全買大腸 ($S = 0, C = 4$)：$\text{成本 } = 4 \times 0 + 1 \times 4 = 4 \text{ 美元}$
    • 全買鯊魚肉 ($S = 4, C = 0$)：$\text{成本 } = 4 \times 4 + 1 \times 0 = 16 \text{ 美元}$
  3. 結論：最適組合為角解 (Corner Solution)，即 $S^* = 0, C^* = 4$（完全不餵鯊魚肉，全餵大腸），每日最低成本為 4 美元。

第四部分：數學工具補充與繪圖輔助 ($2.7$)

  • 對數與指數律： $$\ln(x \cdot y) = \ln x + \ln y, \quad \ln\left(\frac{x}{y}\right) = \ln x - \ln y, \quad \ln(x^n) = n \ln x$$
  • 微觀數據與變化率：

    對數微分 $\frac{d(\ln x)}{dx} = \frac{1}{x} \implies d(\ln x) = \frac{dx}{x}$，代表變數 $x$ 的百分比變化率，常用於計算點彈性與計量模型建立。
