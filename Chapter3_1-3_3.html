第一部分：3.1 生產實驗的限制（報告：敏彰）

傳統經濟學常透過實地或控制場域的「生產實驗」觀察投入與產出的關係，以繪製等產量曲線。然而傳統生產實驗面臨三大主要限制：

  1. 無法解釋替代背後的原因：生產實驗僅能描述投入要素間可相互替代（如多用機器少用人力），但無法說明背後的經濟機制或運作原因（例如：是因為規模效益變快，還是人力等待機器的閒置時間減少？）。
  2. 投入要素增加導致成本幾何級數上升：實驗若僅比較 2 種（最多 3 種）要素尚可進行，但當要素增加（例如加上原料、包材、電力、空間等），需要的組合測試數量龐大，實驗成本與時間會急遽增加，甚至干擾實際營業。
  3. 無法預測新要素的替代效果：舊有實驗無法套用到「全新投入要素」上（例如：飲料店引進自動調配機，或農場使用基因改造新品種），必須重新設計實驗。
🥤 課堂生活案例：手搖飲料店配置
  • 配置替代：1 位店員搭配封口機 vs 2 位純手動店員，均能產出 100 杯飲料，顯示人力與設備存在替代關係。
  • 實驗限制：若要同時考慮店員人數、自動調飲機、包材與冰塊配置，測試組合會過度繁雜；且引入新設備後，必須重新分析清潔維護與補充原料的人力成本。

第二部分：3.2 最低成本飲食問題與線性規劃（報告：建廷）

為了克服傳統生產實驗的限制，1940年代（二戰期間/二戰後）學者引入了線性規劃（Linear Programming），最初應用於 George Stigler (1945) 所提出的「最低成本飲食問題 (Diet Problem)」。

1. 線性規劃標準模型架構

設 $N$ 為營養素種類，$M$ 為食物種類；$C_j$ 為第 $j$ 種食物之單價，$X_j$ 為食物使用量；$A_{ij}$ 為每單位第 $j$ 種食物含第 $i$ 種營養素之數量，$B_i$ 為第 $i$ 種營養素每日最低需求量：

$$\text{目標函數（極小化總成本）：} \min \sum_{j=1}^{M} C_j X_j$$ $$\text{限制條件（營養約束）：} \sum_{j=1}^{M} A_{ij} X_j \ge B_i \quad (i=1, \dots, N)$$ $$\text{非負限制：} X_j \ge 0 \quad (j=1, \dots, M)$$

2. 經典數據範例：高麗菜（甘藍）與馬鈴薯

營養要素 / 食物 高麗菜 ($X_1$) 馬鈴薯 ($X_2$) 每日最低需求量 ($B_i$)
熱量 (kCal) 96 325 3,000
蛋白質 (g) 4.63 7.63 70
維生素 A (IU) 266 152 5,000
每磅單價 ($C_j$) $0.3 美元 $0.2 美元 -
$$\min \; 0.3 X_1 + 0.2 X_2$$ $$\text{s.t. } 96 X_1 + 325 X_2 \ge 3000 \quad (\text{熱量})$$ $$4.63 X_1 + 7.63 X_2 \ge 70 \quad (\text{蛋白質})$$ $$266 X_1 + 152 X_2 \ge 5000 \quad (\text{維生素 A})$$ $$X_1 \ge 0, \quad X_2 \ge 0$$

最適內部解：求解切點與約束邊界交點，得 $X_1^* \approx 16.27$ 磅（高麗菜）、$X_2^* \approx 4.43$ 磅（馬鈴薯），每日最低飲食總成本約為 $5.76 美元。

對偶問題 (Dual Problem)： 由 John von Neumann 提出，對偶問題轉為「計算每單位營養素的邊際隱藏價值（影子價格 Shadow Price）並予以最大化」，可用於估算補充劑或純營養品之經濟價值。

第三部分：3.3 線性規劃技術與演算工具（報告：斯育）

1. 求解演算法演進

  • 幾何繪圖法： 適用於 2 種變數（平面圖形交點），超過 3 種變數則無法直觀繪製。
  • 單形法 (Simplex Method)： 早期代數演算法，沿著可行域的邊界端點（Vertex）逐步移動尋求最佳解。
  • 內部點演算法 (Interior-Point Algorithm)： 近代演算法，直接從可行域內部穿過並快速收斂至最佳端點。

2. 求解軟體與數位工具操作

課本早期介紹 Maple/MuPAD 等代數軟體系統。老師於課堂現場示範現代化替代工具：

🛠️ 工具 1：Excel 規劃求解 (Solver) 步驟
  1. 點選「檔案」$\rightarrow$「選項」$\rightarrow$「增益集」$\rightarrow$ 執行「規劃求解增益集」。
  2. 建立目標函數儲存格（如 `=0.3*X1 + 0.2*X2`）。
  3. 開啟「規劃求解」，設定目標儲存格極小化，並新增三條營養限制式與非負限制。
  4. 點選「求解」，精準得到 $X_1 = 16.268$, $X_2 = 4.425$，最小成本 $5.765$ 美元。
🌐 工具 2：線上線性規劃求解器 (Web Solver / AI)

若使用平板（如 iPad 無法安裝增益集），可直接使用網頁版 Linear Programming Solver 或將不等式直接輸入給 AI 進行分析計算，同樣能精準求得相同最佳解。
