3.7 附錄：線性規劃軟體應用 (Software for Linear Programming)

John P. Burkett《Microeconomics: Optimization, Experiments, and Behavior》第三章實務程式範例

本節導讀：從手算單純形表到高維度電腦求解

在前面幾節中，我們學習了線性規劃（Linear Programming）的矩陣表述、幾何極點與對偶理論。然而，當真實商業問題包含數百種食物/產品（$n \ge 100$）與幾十種限制條件（$m \ge 50$）時，人工手算單純形表（Simplex Tableaux）已不可能。

本附錄（3.7 節）介紹現代個體經濟學者與運籌分析師最常使用的軟體工具（如 Python、R、Excel Solver 以及專業求解器 Gurobi/CPLEX），並演示如何將矩陣 $\mathbf{A}, \mathbf{b}, \mathbf{c}$ 直接輸入軟體快速求解，並自動產出對偶變數（影子價格）。

1. 標準型矩陣與軟體介面對接

軟體求解器通常要求將問題統一化為「標準極小化」或「標準極大化」形式。以 3.2 節的飲食問題為例：

$$\min_{\mathbf{x}} \quad \mathbf{c}^T \mathbf{x} \quad \text{s.t.} \quad \mathbf{A}_{ub} \mathbf{x} \le \mathbf{b}_{ub}, \quad \mathbf{x} \ge \mathbf{0}$$

注意：多數軟體套件（如 Python 的 SciPy）預設限制式方向為「小於等於（$\le$）」。若原問題為大於等於限制 $\mathbf{A}\mathbf{x} \ge \mathbf{b}$（如營養下限），需在兩邊同乘以 $-1$ 轉換為：

$$-\mathbf{A}\mathbf{x} \le -\mathbf{b}$$

Python SciPy 程式碼範例

以下展示求解 3.5 節隨堂練習（穀物與苜蓿飼料成本極小化）的完整程式：

import numpy as np from scipy.optimize import linprog # 1. 成本係數向量 c (穀物 $4, 苜蓿 $3) c = np.array([4, 3]) # 2. 限制矩陣 A_ub 與需求向量 b_ub (大於等於轉小於等於，乘 -1) # 蛋白質: 2*x1 + 1*x2 >= 8 => -2*x1 - 1*x2 <= -8 # 維生素: 1*x1 + 2*x2 >= 7 => -1*x1 - 2*x2 <= -7 A_ub = np.array([ [-2, -1], [-1, -2] ]) b_ub = np.array([-8, -7]) # 3. 變數邊界 (x1 >= 0, x2 >= 0) x_bounds = (0, None) # 4. 執行單純形法/內點法求解 res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=[x_bounds, x_bounds], method='highs') # 5. 輸出最適解 x* 與最小總成本 C* print(f"最適購買數量 x*: {res.x}") # 輸出 [3., 2.] print(f"最小總成本 C*: {res.fun}") # 輸出 18.0 print(f"對偶影子價格 (Shadow Prices): {res.ineqlin.marginals}") # 輸出 [1.6667, 0.6667]

2. 常用個體經濟學與運籌軟體比對

Python (SciPy / PuLP / Pyomo)

適用場景： 開源、適合大規模數據整合、資料科學與機器學習工作流。

優勢： 能直接讀取 Pandas 資料框架，一鍵對接 API 輸入即時市場價格。

R (lpSolve / ROI)

適用場景： 計量經濟學研究、實證數據分析與統計建模。

優勢： 與 R 的統計與圖表套件（ggplot2）無縫接軌，方便繪製可行域與敏感性分析圖。

Excel Solver (規劃求解)

適用場景： 商業管理簡報、快速試算表建立與教學演示。

優勢： 具備直觀的圖形介面（GUI），點擊即可自動產出「敏感性報告（Sensitivity Report）」，直接顯示影子價格與許容增減量（Allowable Increases）。

商業求解器 (Gurobi / CPLEX)

適用場景： 晶圓廠排程、航空路網調度等包含數百萬變數的超大規模計算。

優勢： 求解速度極快，針對混合整數規劃（MILP）優化達到極限效能。

3. 產業時事：物流巨頭與外送平台的自動化 LP 引擎

📰 產業時事：FedEx、順豐與外送平台即時派單的軟體求解架構

背景分析： 現代物流業者（如 FedEx、順豐）或外送平台（如 UberEats）每分鐘有數萬張訂單需要匹配司機。車輛載重與容量（限制條件 $\mathbf{b}$）有限，而路線營運成本（$\mathbf{c}$）需被極小化。

個體經濟學與軟體應用：

  • 後端運算引擎： 後端伺服器自動呼叫高效能 LP 求解器（如 Gurobi），在數百毫秒內求解包含多限制條件的線性規劃陣列，決定最適派遣向量 $\mathbf{x}^*$。
  • 動態加價機制： 求解器輸出的「對偶影子價格 $y_i^*$」直接回傳至動態定價系統。當某區域外送員數量極度緊缺時，影子價格飆升，系統便自動向顧客收取「尖峰加算費用（Surge Pricing）」。

4. 生活案例：碩士生論文數據分析與日常預算求解

🎓 生活案例：用 Python / Excel 求解自己的碩士研發與時間規劃

情境體驗： 碩士生在撰寫學術論文時，需建立一個描述供應鏈或企業成本的實證模型。你無需手算高維度矩陣，只需在 Jupyter Notebook 中載入 Python 套件，即可處理包含上百個變數的模型。

模型化思考：

  • 學會使用軟體求解 LP，讓你從繁瑣的代數運算中解放出來，將注意力集中在「經濟學假設是否合情理」以及「如何詮釋影子價格的商業含義」。
  • 你甚至可以使用 Excel 規劃求解，輸入自己每個月的房租、伙食與娛樂開銷限制，求解滿足最低營養與社交需求下的最小支出組合。
