3.3 線性規劃求解技巧 (Linear Programming Techniques)

John P. Burkett《Microeconomics: Optimization, Experiments, and Behavior》第三章專題

本節導讀：從幾何可行域到對偶理論的演算法核心

在 3.2 節中，我們將最低成本飲食問題表述為標準的矩陣形式 $\min \mathbf{c}^T \mathbf{x} \text{ s.t. } \mathbf{A}\mathbf{x} \ge \mathbf{b}, \mathbf{x} \ge \mathbf{0}$。本節（3.3 節）將探討如何從幾何圖解與代數演算法層面求解線性規劃問題。

John P. Burkett 教授深入介紹了 George Dantzig 提出的單純形法（Simplex Method）、凸多面體（Convex Polyhedron）幾何極點性質，以及極具經濟學深度的對偶理論（Duality Theory）與影子價格（Shadow Prices）。

1. 幾何直覺與極點定理 (Extreme Point Theorem)

線性規劃問題的約束條件構成了一個凸多面體（Convex Polyhedron），稱為可行域（Feasible Region）。目標函數則是一組平行超平面。

核心基本定理

若線性規劃問題存在有限最優解，則至少有一個最優解部位於可行域的極點（Extreme Point / Vertex）上。

$$\text{If } \mathbf{x}^* \text{ is an optimal solution}, \implies \mathbf{x}^* \in \text{Extreme Points of } \{\mathbf{x} \mid \mathbf{A}\mathbf{x} \ge \mathbf{b}, \mathbf{x} \ge \mathbf{0}\}$$

這項定理極大地簡化了尋找最優解的範圍：我們無需在無限個連續點組成的可行域內部漫無目的地搜尋，只需檢查有限個極點即可。

2. 單純形法 (Simplex Method) 與鬆弛變數 (Slack Variables)

單純形法是一種從一個極點移動到相鄰極點、並確保目標函數值不斷改善的代數演算法。

標準型轉換（Standard Form）

為了進行矩陣運算，我們引入非負的鬆弛變數（Slack Variables, $s_i \ge 0$）或剩餘變數（Surplus Variables），將不等式約束轉化為等式約束：

$$\sum_{j=1}^{n} a_{ij} x_j - s_i = b_i \quad (s_i \ge 0, \quad i = 1, 2, \dots, m)$$

在代數上，單純形法就是不斷選取 $m$ 個獨立變數作為基變數（Basic Variables），並將其餘 $n$ 個非基變數設為 0，藉由樞紐旋轉（Pivoting）計算基可行解（Basic Feasible Solution），直至滿足最優性檢定條件（Optimality Test）。

3. 對偶理論 (Duality Theory) 與影子價格

每一個原問題（Primal Problem）都對應著一個對偶問題（Dual Problem）。對偶理論揭示了資源配置與資源定價之間極為深刻的對稱關係。

原問題 (Primal Problem)

極小化成本：

$$\min_{\mathbf{x}} \quad \mathbf{c}^T \mathbf{x}$$ $$\text{s.t.} \quad \mathbf{A}\mathbf{x} \ge \mathbf{b}, \quad \mathbf{x} \ge \mathbf{0}$$

決策變數 $\mathbf{x}$： 食物或產品的購買數量。

對偶問題 (Dual Problem)

極大化虛擬隱性價值：

$$\max_{\mathbf{y}} \quad \mathbf{b}^T \mathbf{y}$$ $$\text{s.t.} \quad \mathbf{A}^T \mathbf{y} \le \mathbf{c}, \quad \mathbf{y} \ge \mathbf{0}$$

對偶變數 $\mathbf{y}$： 營養素或資源的隱性價格（影子價格）。

對偶強定理 (Strong Duality Theorem) 與互補鬆弛性

若原問題存在最適解 $\mathbf{x}^*$，則對偶問題亦存在最適解 $\mathbf{y}^*$，且兩者的最適目標函數值完全相等：

$$\mathbf{c}^T \mathbf{x}^* = \mathbf{b}^T \mathbf{y}^*$$

其中對偶變數 $y_i^* = \frac{\partial C^*}{\partial b_i}$ 代表第 $i$ 種營養素限制邊界 $b_i$ 增加一單位時，總成本 $C^*$ 的邊際增加量，即影子價格（Shadow Price）。

4. 產業時事：AWS/GCP 雲端伺服器集群的單純形調度演算法

📰 科技時事：雲端服務商算力節點分配與對偶影子價格定價

背景新聞： 大型雲端業者（如 Amazon AWS、Google Cloud）每日需在數百萬個虛擬機與容器（Pods）之間調配 CPU、GPU、RAM 與網絡頻寬。資源總量 $\mathbf{b}$ 有限，而客戶訂單 $\mathbf{x}$ 帶來不同收益 $\mathbf{c}$。

個體經濟學解析：

  • 單純形法調度： 資料中心作業系統實質上運行著大型線性規劃演算法，在凸多面體的可行域極點之間迅速尋找最佳算力派發組合 $\mathbf{x}^*$。
  • 影子價格與動態定價： 對偶變數 $\mathbf{y}^*$ 計算出每一 G 記憶體或每一單位 GPU 頻寬的影子價格。當某一區域 RAM 資源達到飽和瓶頸（鬆弛變數 $s_i = 0$）時，對偶強定理顯示其影子價格 $y_i^* > 0$，這正是雲端業者調升該時段 Spot Instance（競價實例）價格的理論依據。

5. 生活案例：碩士生畢業學分與論文時間分配的影子價格

🎓 生活案例：研究生有限總時間下的學習效益極大化

情境體驗： 碩士生在學期末面臨兩大任務：修滿畢業所需學分、撰寫學術論文。你每週可支配的時間只有 60 小時（資源約束 $b_1$），精力容量只有 100 點（資源約束 $b_2$）。修課與寫論文兩種活動（Activities）各自消耗不同的時間與精力，並產生不同的職涯邊際回報。

模型化思考：

  • 你選擇的最佳時間分配，必定位於時間與精力雙重限制線交會的「幾何極點」上。
  • 這段時間的影子價格 $y_{time}^*$ 代表：如果一天能多出 1 小時（$b_1$ 增加 1），你的總學習與職涯效益能增加多少？若時間有剩餘（鬆弛變數 $s_{time} > 0$），則時間的影子價格為 0，說明此時限制畢業效益的瓶頸是精力而非時間。

6. 碩士班進階討論題 (Advanced Discussion)

請各位同學結合 Burkett 教材 3.3 節內容，思考並準備下週課堂研討：

  1. 互補鬆弛性定理 (Complementary Slackness Theorem)： 證明在最適點上，$y_i^* \cdot \left( \sum_{j=1}^n a_{ij} x_j^* - b_i \right) = 0$。請從經濟學角度解釋：為何當某項資源未被充分利用（有剩餘）時，其影子價格必須等於零？
  2. 退化現象 (Degeneracy)： 在單純形法求解過程中，若出現多條限制線交於同一極點，可能會引發「退化」與無限循環（Cycling）。在現實商業決策中，退化代表了什麼樣的資源冗餘狀態？
